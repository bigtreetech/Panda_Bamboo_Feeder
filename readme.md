## Introduction
The BIQU Panda Bamboo Feeder is a smart filament Refill buffer system for FDM printers. Powered by ESP32 with WiFi, it features active Filament buffering, auto load/unload, smart filament Refill, and multi-unit linkage. Ideal for flexible filaments, large spools, long paths,leftover spools and unattended printing.

Specially optimized for Bambu Lab X1 / P1 / P2 / A1 series with dedicated power interfaces.

## Key Features
- **Active Filament Buffering – Ensures stable feeding for soft, brittle, or heavy spools (5kg+), reducing under-extrusion and stringing.
- **Auto Load/Unload – One-touch feeding to the print head with sync commands; press to retract.
- **Smart Filament Backup – Single unit switches between two spools; link up to three units for four-spool marathon.
- **WiFi Remote Control – ESP32-based, accessible via web UI or BQ App.
- **Premium Build – Injection-molded semi-transparent black case.
- **Wide Compatibility – Works with most FDM printers, with plug-and-play optimization for Bambu Lab X1/P1/P2/A1.
